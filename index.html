写给陪伴孩子的你

每一个字，
都是一座小小的岛。

这里是「汉字小岛：趣味识字」的支持站。我们正在设计一款适合 5～7 岁儿童、由家长陪伴使用的中文识字游戏。

● 开发中 · 尚未发布

目前处于规划与视觉设计阶段。长期课程目标为 1,500 个汉字；这不代表现已有完整课程或可下载的游戏。

01 / 认识小岛

为轻松识字而设计

计划以岛屿探索和短时互动帮助孩子接触汉字。课程将逐步开发，实际内容与功能以正式发布版本为准。

02 / 家长陪伴

重要操作交给家长

计划设置家长区，将支持联系、外部链接及重要设置放在家长验证之后。本网站面向家长和监护人，所有联系请由成人完成。

03 / 本地记录

把学习进度留在设备上

当前设计无需账号，识字与关卡进度、声音设置保存在设备本地，不使用开发者业务服务器。详细边界请阅读隐私说明。

家长常见问题

现在可以下载或试玩吗？

尚未发布。此页面仅提供开发阶段的产品与支持信息，不提供游戏下载。发布日期、首发课程及可用功能将在确定后更新。

将如何收费？

计划采用付费下载、一次买断，不设置内购或订阅。价格和首发地区尚未确定，正式价格以发布时的 App Store 页面为准。目前尚未发布，也未开放购买。

需要注册账号或上传孩子的信息吗？

当前设计无需账号，也不要求孩子提供姓名、生日、照片或联系方式。计划中的学习记录保存在本地；联系支持时，请由家长发送邮件，避免包含孩子的个人信息。

进度能在其他设备恢复吗？

当前未设计开发者云同步。系统备份是否保留或恢复数据取决于设备设置与最终实现。删除 App 或清除浏览器中的游戏数据可能丢失进度；正式版本的操作说明将在发布前核对。

网站和游戏的隐私处理一样吗？

游戏的当前设计以本地记录为主。访问这个网站会向 GitHub Pages 发出网络请求；发送支持邮件也会经过邮件服务。请参阅完整隐私说明。

For parents and guardians

A little island for every character.

Welcome to the support site for Hanzi Island (汉字小岛：趣味识字), a Chinese character learning game being designed for children aged 5–7 with a parent or guardian.

● In development · Not yet released

The project is currently in planning and visual design. Our long-term curriculum goal is 1,500 Chinese characters; a complete curriculum and a downloadable game are not yet available.

01 / Discover

Designed for playful learning

Island exploration and short activities are planned to introduce Chinese characters. Lessons will be developed gradually. Available content and features will depend on the released version.

02 / Together

Important actions for adults

A parent area is planned, with an adult check before support contact, external links, and important settings. This website is intended for parents and guardians. An adult should handle all support communication.

03 / On device

Learning progress stays local

The current design requires no account. Character and level progress and sound settings are intended to stay on the device, with no developer-operated backend. See our privacy notice for the boundaries.

Questions from parents

Can we download or try the game now?

It has not been released. This website provides development-stage product and support information, with no game download. We will update the release date, initial lessons, and available features when confirmed.

How will the game be priced?

A one-time paid download is planned, with no in-app purchases or subscriptions. Pricing and initial release regions have not yet been determined. The price will be shown on the App Store at release. The game is not yet released or available to purchase.

Will my child need an account or share personal information?

The current design requires no account, name, birth date, photo, or contact details. Planned learning records stay on the device. A parent should email support and avoid including a child's personal information.

Can progress be restored on another device?

Developer-operated cloud sync is not currently planned. Whether system backups retain or restore data depends on device settings and the final implementation. Deleting the app or clearing browser game data may erase progress. Instructions will be verified before release.

Do the website and game handle data in the same way?

The game's current design uses local records. Visiting this website sends network requests to GitHub Pages, and support messages pass through email services. Please read the full privacy notice.
